# CAN 协议说明

## 1. 概述

本项目使用标准帧 `CAN 2.0A`，数据长度固定按 8 字节处理。多字节整数统一使用小端格式。

每台电机出厂或擦除参数后处于未配置状态：

- 管理节点 ID：`0x7E`
- 管理命令 ID：`0x17E`
- 管理应答 ID：`0x1FE`
- 管理上报 ID：`0x27E`
- 未配置电机以 2Hz 频率上报 `UID32`
- 未配置电机不响应普通控制命令，也不主动上报电机状态
- 配置业务 CAN ID 后进入运行状态，并使用业务节点 ID 响应控制命令

`UID32` 是由 STM32F103 96 位 UID 派生出的 32 位短 UID，用于在管理 ID 下区分同总线上的多台电机。

## 2. ID 规划

标准帧 ID 由基础 ID 与节点 ID 相加得到：

| 类型 | 标准帧 ID |
| --- | --- |
| 主机命令 | `0x100 + node_id` |
| 电机应答 | `0x180 + node_id` |
| 电机上报 | `0x200 + node_id` |
| OTA 控制 | `0x400 + node_id` |
| OTA 响应 | `0x500 + node_id` |

管理节点固定使用 `node_id = 0x7E`。

## 3. 通用帧格式

| 字节 | 含义 |
| --- | --- |
| Byte0 | 命令码 |
| Byte1~Byte7 | 命令参数 |

应答帧格式：

| 字节 | 含义 |
| --- | --- |
| Byte0 | 回显命令码 |
| Byte1 | 状态码 |
| Byte2~Byte7 | 附加返回数据 |

状态码：

| 状态码 | 含义 |
| --- | --- |
| `0x00` | 成功 |
| `0x01` | 命令非法 |
| `0x02` | 参数非法 |
| `0x03` | 模式非法 |
| `0x04` | CAN 错误 |

## 4. 管理命令

### 4.1 未配置发现上报

- 命令码：`0x60`
- 方向：电机 -> 主机
- 帧 ID：`0x27E`
- 频率：2Hz，仅未配置状态上报

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x60` |
| Byte1 | 配置状态，`0 = 未配置`，`1 = 已配置` |
| Byte2 | 当前节点 ID，未配置时为 `0x7E` |
| Byte3~Byte6 | `UID32`，小端 |
| Byte7 | 保留 |

### 4.2 识别灯效

- 命令码：`0x61`
- 方向：主机 -> 电机
- 帧 ID：`0x17E`

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x61` |
| Byte1 | 闪烁频率，单位：Hz，固件限制到 1~20Hz |
| Byte2 | 持续时间，单位：秒，0 表示默认 5 秒，最大 60 秒 |
| Byte3~Byte6 | 目标 `UID32`，小端 |
| Byte7 | 保留 |

匹配 `UID32` 的电机会进入识别灯效，并通过 `0x1FE` 应答：

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x61` |
| Byte1 | 状态码 |
| Byte2 | 实际闪烁频率，单位：Hz |
| Byte3 | 实际持续时间，单位：秒 |
| Byte4~Byte7 | `UID32`，小端 |

### 4.3 配置业务 CAN ID

- 命令码：`0x62`
- 方向：主机 -> 电机
- 帧 ID：`0x17E`

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x62` |
| Byte1 | 新业务节点 ID，范围 `0x01~0x7F`，不能为 `0x7E` |
| Byte2 | 保留 |
| Byte3~Byte6 | 目标 `UID32`，小端 |
| Byte7 | 保留 |

匹配 `UID32` 且参数合法后，固件会保存 `can_id` 与 `can_configured = 1`，切换到运行状态，并重新配置 CAN 过滤器。

应答帧 ID 为 `0x1FE`：

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x62` |
| Byte1 | 状态码 |
| Byte2 | 新业务节点 ID |
| Byte3~Byte6 | `UID32`，小端 |
| Byte7 | 保留 |

## 5. 普通控制命令

普通控制命令只在电机已配置后生效。未配置状态下，即使收到普通控制命令也不会响应。

### 5.1 设置运行模式

- 命令码：`0x01`

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x01` |
| Byte1 | 使能，`0 = 停机`，`1 = 运行` |
| Byte2 | 控制模式，`0 = 电流`，`1 = 速度`，`2 = 位置` |
| Byte3~Byte7 | 保留 |

### 5.2 设置电流目标

- 命令码：`0x02`

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x02` |
| Byte1~Byte4 | 电流目标，`int32`，单位：q 轴内部控制量 |
| Byte5~Byte7 | 保留 |

### 5.3 设置速度目标

- 命令码：`0x03`

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x03` |
| Byte1~Byte4 | 速度目标，`int32`，单位：mrad/s |
| Byte5~Byte7 | 保留 |

### 5.4 设置位置目标

- 命令码：`0x04`

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x04` |
| Byte1~Byte4 | 位置目标，`int32`，单位：mrad |
| Byte5~Byte7 | 保留 |

## 6. PID 命令

PID 参数编号：

| 编号 | 含义 |
| --- | --- |
| `0x00` | `P` |
| `0x01` | `I` |
| `0x02` | `D` |
| `0x03` | `I_ACC_MAX` |
| `0x04` | `OUT_MAX` |

`P`、`I`、`D` 按 `x1000` 的整数传输，`I_ACC_MAX` 和 `OUT_MAX` 直接按内部整数值传输。

| 命令码 | 方向 | 含义 |
| --- | --- | --- |
| `0x10` | 主机 -> 电机 | 设置速度环参数 |
| `0x11` | 主机 -> 电机 | 读取速度环参数 |
| `0x12` | 主机 -> 电机 | 设置位置环参数 |
| `0x13` | 主机 -> 电机 | 读取位置环参数 |

设置参数帧：

| 字节 | 含义 |
| --- | --- |
| Byte0 | 命令码 |
| Byte1 | 参数编号 |
| Byte2~Byte5 | 参数值，`int32` |
| Byte6~Byte7 | 保留 |

读取参数帧：

| 字节 | 含义 |
| --- | --- |
| Byte0 | 命令码 |
| Byte1 | 参数编号 |
| Byte2~Byte7 | 保留 |

## 7. 参数与版本命令

| 命令码 | 含义 |
| --- | --- |
| `0x20` | 设置业务 CAN 节点 ID，配置后仍保持已配置状态 |
| `0x21` | 读取当前 CAN 节点 ID |
| `0x22` | 读取 App 版本号 |
| `0x23` | 设置电机主动上报配置 |
| `0x24` | 读取电机主动上报配置 |
| `0x30` | 零点校准并保存 |
| `0x31` | 读取零点 |
| `0x40` | 进入 Boot OTA |

读取 App 版本号应答负载：

| 字节 | 含义 |
| --- | --- |
| Byte2 | 主版本号 |
| Byte3 | 次版本号 |
| Byte4 | 修订版本号 |

当前初始版本为 `1.0.0`：

```text
DATA = 22 00 01 00 00 00 00 00
```

设置电机主动上报配置 `0x23`：

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x23` |
| Byte1 | 上报使能，`0 = 关闭`，`1 = 打开` |
| Byte2~Byte3 | 上报周期，`uint16`，单位：毫秒，范围 `10~60000` |
| Byte4~Byte7 | 保留 |

读取电机主动上报配置 `0x24`：

| 字节 | 含义 |
| --- | --- |
| Byte0 | `0x24` |
| Byte1~Byte7 | 保留 |

`0x23` 和 `0x24` 的应答负载：

| 字节 | 含义 |
| --- | --- |
| Byte2 | 上报使能，`0 = 关闭`，`1 = 打开` |
| Byte3~Byte4 | 上报周期，`uint16`，单位：毫秒 |
| Byte5~Byte7 | 保留 |

## 8. 电机主动上报

电机主动上报默认关闭，默认周期为 `10ms`。已配置电机只有在 `0x23` 打开主动上报后，才会按配置周期上报位置和速度：

| 命令码 | 含义 |
| --- | --- |
| `0x80` | 位置上报，Byte1~Byte4 为 `int32`，单位：mrad |
| `0x81` | 速度上报，Byte1~Byte4 为 `int32`，单位：mrad/s |

未配置电机只发送管理发现上报，不发送位置和速度上报。

## 9. 灯效区分

| 固件状态 | 灯效 |
| --- | --- |
| App 未配置 | 2 秒周期短闪一次 |
| App 已配置运行 | 1.5 秒周期三连闪 |
| App 识别 | 按上位机指定频率闪烁 |
| Boot 待机 | 1.4 秒周期双闪 |
| Boot 升级中 | 5Hz 快闪 |

## 10. 过滤器说明

App CAN 初始化后接收：

```text
0x17E
0x100 + node_id
0x400 + node_id
```

未配置时 `node_id = 0x7E`，但普通控制命令仍会被协议层忽略，只处理管理命令和 OTA 启动帧。
