# PCAN 电机上位机

## 1. 功能页面

`scripts/pcan_motor_tool.py` 通过顶部页签切换三个工作页面，共用同一个 PCAN 连接和日志区域。

### 1.1 新电机配置

- 扫描管理节点上报，并按 UID32 显示未配置和已配置电机。
- 选中扫描结果后，可直接识别对应电机。
- 节点 ID 使用输入框手工填写，允许范围为 `0x01~0x7F`，但不能使用管理节点 `0x7E`。
- 配置极对数、相序、零点校准和主动上报状态。
- 相序只保留两个选项：`phase_map=0` 正序和 `phase_map=1` 反序。
- 可执行正向或反向绕组测试。测试会写入当前相序、校准零点、打开 `2ms` 角度上报，并施加限时电流，结束后自动关闭输出。
- 绕组测试电流控制量限制为 `1~3000`，持续时间限制为 `50~500ms`。

绕组测试根据机械角度变化判断结果。正向测试得到正位移、反向测试得到负位移时显示“方向一致”；位移方向不符时应切换相序重新测试。位移小于 `20mrad` 时不会判断方向，应先检查接线、供电和电流设置。

### 1.2 电机调试

- 扫描 `0x01~0x7F` 中除 `0x7E` 外的全部业务节点。
- 在线电机按节点编号从大到小排列，点击表格行可切换当前调试电机。
- 表格显示位置 `mrad`、位置 `deg`、速度 `mrad/s`、版本、零点和 FOC 配置。
- 支持电流、速度、位置三种控制模式，并在目标输入框旁显示对应单位。
- 速度环和位置环 PID 参数直接嵌入调试页，不再打开独立窗口。
- FOC 参数区可读取或写入极对数、母线电压、FOC 频率、角度采样频率和相序。
- 曲线显示当前位置 `mrad` 和速度 `mrad/s`，数值与图例均带单位。
- 支持主动上报设置、零点校准、停止输出和 FOC 高速诊断记录。

PID 参数使用 IEEE 754 小端 `float32` 传输。`I_ACC_MAX` 和 `OUT_MAX` 的允许范围为 `0~32767`。速度环使用命令 `0x10/0x11`，位置环使用命令 `0x12/0x13`。

### 1.3 电机 OTA

- 自动扫描仓库 `firmware_package/motor_duck_v*/manifest.json`。
- 只列出 manifest 中存在 `ota_app_bin` 且固件文件有效的版本，并按版本号从新到旧排列。
- 可扫描在线电机并选择 OTA 节点。
- OTA 在后台调用 `scripts/pcan_ota.py`，进度期间界面保持响应，子进程日志显示在公共日志区。
- 如果开始 OTA 时上位机已连接 PCAN，会先释放通道；OTA 结束后自动恢复原通道连接。

## 2. 启动

默认使用 `PCAN_USBBUS1` 和 `1M` 波特率：

```powershell
python scripts/pcan_motor_tool.py
```

指定通道和波特率：

```powershell
python scripts/pcan_motor_tool.py --channel PCAN_USBBUS1 --bitrate 1M
```

如果连接时报通道无效，可点击顶部“扫描”探测 `PCAN_USBBUS1~PCAN_USBBUS16`。

## 3. 控制单位

| 模式 | 编号 | 目标单位 |
| --- | --- | --- |
| `current` | `0` | 电流控制量 |
| `speed` | `1` | `mrad/s` |
| `position` | `2` | `mrad` |

“停止当前”会切换到关闭使能的电流模式，固件同时清零控制目标并关闭功率输出。“停止全部”只作用于当前已扫描发现的在线节点。

## 4. 主动上报与曲线

上报配置使用命令 `0x23`，读取配置使用命令 `0x24`。工具按输入频率换算周期：

```text
period_ms = round(1000 / hz)
```

上报周期允许范围为 `2~60000ms`，因此界面最高配置频率为 `500Hz`。曲线窗口允许范围为 `0.2~120s`。

## 5. FOC 高速诊断记录

“开始记录”会武装固件 RAM 中的高速环形缓存。记录发生在角度传感器更新周期内，不通过 CAN 实时发送。

- 缓存容量为 512 点。
- `|speed| >= 10000mrad/s` 时触发，再记录 384 点后冻结。
- 每点包含传感器角度、机械角度、电角度、速度、q 轴目标和三相 PWM。
- 点击“停止并保存”后，工具通过 CAN 分片读取并保存为 UTF-8 BOM CSV。

未达到自动触发条件时，点击停止会立即冻结当前环形窗口。
